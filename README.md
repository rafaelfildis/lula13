# Apuração 2026

Ferramentas para acompanhar a apuração das Eleições 2026 a partir dos JSON públicos do TSE (resultados.tse.jus.br).

- [`apuracao.mjs`](apuracao.mjs): script de terminal que mostra presidente e governadores do 2º turno, atualizando a cada 60 s (`node apuracao.mjs --help` nos comentários do topo).
- [`painel/`](painel/): protótipo de painel web com mapa do Brasil em tempo real e sala ao vivo com chat, câmera e microfone. Veja [painel/README.md](painel/README.md).

Requer Node 18+.
